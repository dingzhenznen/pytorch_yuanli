torch.softmax( dim=-1) 举一个简单的例子


• dim=-1 表示：沿着最后一个维度做 softmax。

  比如：

  import torch

  x = torch.tensor([
      [1.0, 2.0, 3.0],
      [1.0, 1.0, 1.0],
  ])

  y = torch.softmax(x, dim=-1)

  print(y)
  print(y.shape)

  输出大概是：

  tensor([
      [0.0900, 0.2447, 0.6652],
      [0.3333, 0.3333, 0.3333]
  ])
  torch.Size([2, 3])

  原来的 shape 是：

  x.shape = (2, 3)

  softmax 后：

  y.shape = (2, 3)

  形状不变。

  这里 dim=-1 就是对每一行的最后一维做 softmax：

  [1.0, 2.0, 3.0] -> [0.0900, 0.2447, 0.6652]
  [1.0, 1.0, 1.0] -> [0.3333, 0.3333, 0.3333]

  每一行加起来都是 1：

  0.0900 + 0.2447 + 0.6652 = 1
  0.3333 + 0.3333 + 0.3333 = 1

  如果是注意力分数：

  attn_scores.shape = (2, 4, 3, 3)
  attn_probs = torch.softmax(attn_scores, dim=-1)

  意思就是：对最后那个 3 做 softmax。

  也就是对每个 query token 看所有 key token 的分数做归一化：

  每一行变成概率分布

  例如某个 batch、某个 head：

  attn_scores[0, 0] = torch.tensor([
      [1.0, 2.0, 3.0],
      [3.0, 1.0, 0.0],
      [0.5, 0.5, 0.5],
  ])

  做 dim=-1 后：

  [
      [0.0900, 0.2447, 0.6652],
  ]

  仍然是：

  shape = (3, 3)

  只是每一行都归一化成概率。


› 举一个三维矩阵的例子


• 比如一个三维 tensor：

  import torch

  x = torch.tensor([
      [
          [1.0, 2.0, 3.0],
          [1.0, 1.0, 1.0],
      ],
      [
          [3.0, 1.0, 0.0],
          [2.0, 2.0, 4.0],
      ],
  ])

  print(x.shape)

  它的 shape 是：

  torch.Size([2, 2, 3])

  也就是：

  2 个大块
  每个大块 2 行
  每行 3 个数

  现在做：

  y = torch.softmax(x, dim=-1)

  dim=-1 表示对最后一维做 softmax，也就是每一行的 3 个数分别归一化。

  结果大概是：

  tensor([
      [
          [0.0900, 0.2447, 0.6652],
          [0.3333, 0.3333, 0.3333],
      ],
      [
          [0.8438, 0.1142, 0.0420],
          [0.1065, 0.1065, 0.7870],
      ],
  ])

  shape 不变：

  y.shape
  # torch.Size([2, 2, 3])

  逐行看就是：

  [1, 2, 3] -> [0.0900, 0.2447, 0.6652]
  [1, 1, 1] -> [0.3333, 0.3333, 0.3333]
  [3, 1, 0] -> [0.8438, 0.1142, 0.0420]
  [2, 2, 4] -> [0.1065, 0.1065, 0.7870]

  每个最后一维的和都是 1：

  0.0900 + 0.2447 + 0.6652 = 1
  0.3333 + 0.3333 + 0.3333 = 1
  0.8438 + 0.1142 + 0.0420 = 1
  0.1065 + 0.1065 + 0.7870 = 1

  所以对于：

  x.shape = (2, 2, 3)
  torch.softmax(x, dim=-1)

  含义是：

  固定前两个维度，对最后一维的每组 3 个数做 softmax。

  换句话说：

  x[0, 0, :] 做一次 softmax
  x[0, 1, :] 做一次 softmax
  x[1, 0, :] 做一次 softmax
  x[1, 1, :] 做一次 softmax
